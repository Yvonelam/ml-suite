美客多 API 凭证

用于拉取实时订单、问答与售后数据
在美客多开发者后台创建应用后获取。推荐用「一键授权」：填好 App ID 与 Secret Key 后点授权按钮，系统会自动拿回令牌并长期自动续期，无需手动更换。
一键授权（OAuth 2.0）
下面这一栏必须和后台 Redirect URIs 里登记的一字不差（去后台复制过来）。登记的是根域名就填根域名，登记了完整路径就填完整路径。
如果后台还空着，直接把上面这串复制进去保存即可。
授权时若提示「无法将应用连接到你的账号」，多半是账号 KYC 未完成。先去完成实名验证：
global-selling.mercadolibre.com/kyc
授权失败？手动粘贴回调网址（备用方案）
美客多授权后地址栏会变成 https://ml.yvonework.website/?code=TG-...。把整个网址复制粘贴到下框，我直接换令牌。
或手动填写令牌（高级）
🔔 微信提醒 · 售前提问 + 售后（推送到手机微信）
两类事件自动推微信：① 买家提新的售前问题；② 售后有新动向（平台调解员发来新方案、买家新留言、新纠纷）。都走 PushPlus，不用服务器、免费。
怎么拿 token：手机微信搜公众号「pushplus 推送加」并关注 → 进去点菜单登录 → 在「一对一推送」页面复制 token → 粘贴到下面。 官网 pushplus.plus
